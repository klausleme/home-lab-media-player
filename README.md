# Home Lab Infrastructure

Repositório contendo a infraestrutura como código (IaC) do meu servidor doméstico.
O foco é automação, segurança, portabilidade  e gerenciamento eficiente de mídia usando Docker.

## Stack
- **Plex**: Media Server
- **Linux**: Ubuntu Server
- **Storage**: Gerenciamento via Hardlinks e Permissões Ext4

## Como usar
Renomeie os arquivos `.env.example` para `.env` e ajuste as variáveis conforme seu ambiente.

# Home Lab Infrastructure

Repository containing the infrastructure as code (IaC) of my home server.

The focus is on automation, security, portability, and efficient media management using Docker.

## Stack
- **Plex**: Media Server
- **Linux**: Ubuntu Server
- **Storage**: Management via Hardlinks and Ext4 Permissions

## How to use
Rename the `.env.example` files to `.env` and adjust the variables according to your environment.
